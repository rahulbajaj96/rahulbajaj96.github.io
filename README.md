# Rahul Bajaj— Portfolio

A responsive GitHub Pages portfolio for Rahul Bajaj Senior Mobile App Developer.

## Stack
- HTML
- CSS
- JavaScript
- GitHub Pages

## Before publishing

1. Replace `assets/resume.pdf` with your actual resume PDF.
2. Replace the LinkedIn `#` in `script.js` with your LinkedIn URL.
3. Add real project screenshots to `assets/` if desired.
4. Add project links (GitHub / Play Store / App Store) where available.
5. Review all project descriptions and remove anything that does not accurately represent your work.

## GitHub Pages

Create a public repository named:

`rahulbajaj96.github.io`

Upload all files and enable:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

Your site will then be available at:

`https://rahulbajaj96.github.io/`
